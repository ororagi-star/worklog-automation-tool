# 업무일지 자동 생성 도구

출결 엑셀 파일을 업로드하면 기본 업무일지 양식 2개에 기준일별 실적을 채워 결과 엑셀을 생성하는 Streamlit 앱입니다.

## 로컬 실행

```powershell
python -m pip install -r requirements.txt
python -m streamlit run streamlit_app.py
```

브라우저에서 아래 주소로 접속합니다.

```text
http://localhost:8501
```

## 웹 배포

Streamlit Community Cloud에 배포할 때는 다음 값으로 설정합니다.

```text
Repository: ororagi-star/worklog-automation-tool
Branch: main
Main file path: streamlit_app.py
```

앱은 저장소에 포함된 기본 양식 파일을 사용합니다.

```text
worklog_set1.xlsx
worklog_set2.xlsx
```

사용자가 업로드하는 `low.xlsx`는 저장소에 포함하지 않습니다.

## 양식과 수업 관리

`수업 관리`에서 카테고리, 수업명, 업무일지를 한 줄에 입력하고 `추가`를 누릅니다.
카테고리는 풀다운에서 고르거나 새 이름을 직접 입력할 수 있습니다.
수업을 등록하는 동시에 선택한 업무일지에도 반영됩니다. `미지정`으로 등록하면
수업 목록에만 보관합니다. 빈 카테고리를 미리 등록하거나 이름을 바꾸려면
`카테고리 편집`을 엽니다.

아래 목록에서 수업을 검색하고 각 행의 `수정` 버튼으로 카테고리·수업명·업무일지를
바꿀 수 있습니다. 별도의 업무일지 선택 화면이나 전체 표 저장 단계는 없습니다.

수업 목록은 업무일지와 별개로 유지됩니다. 업무일지 선택을 해제해도 등록된 수업은
남습니다. 카테고리 이름이나 수업명을 수정하면 사용 중인 업무일지에도 반영되며
기존 고유 ID와 원본 수업 연결은 유지됩니다. 수정 창에서 수업을 삭제하면
업무일지에서도 함께 빠집니다. 단, 각 업무일지에는 항목이 하나 이상 필요합니다.
수업이 남아 있는 카테고리는 삭제할 수 없습니다.

원본 수업 연결과 목표 건수/인원은 수업 수정 창의 `추가 설정`에서
지정합니다. 원본과 수업명이 같으면 연결을 비워 두어 자동으로 찾을 수 있습니다.
출결 파일은 원본 수업 목록을 선택하거나 결과를 생성할 때만 필요합니다.

- `자동 연결`: 같은 이름과 기존에 등록된 이름 변경 규칙을 사용합니다.
- `직접 연결`: 선택한 원본 수업만 집계합니다. 출력 이름을 바꿔도 연결은 유지됩니다.
- `집계 제외`: 항목은 출력하되 실적은 비워 둡니다.
- `하루 1건`: 여러 원본 수업을 합쳐도 해당 날짜의 건수는 최대 1건입니다.
- `수업별 합산`: 참석 기록이 있는 원본 수업마다 1건을 집계합니다.

같은 대분류의 항목은 묶어서 출력하며, 가장 빠른 항목의 순서로 대분류 순서를 정합니다.
목표 합계, 일계/월계 합계와 대분류 병합은 저장한 항목 수에 맞춰 생성합니다.
누계는 이번 파일의 월 이전 자료가 없으므로 자동 계산하지 않습니다.
직접 연결한 수업 중 하나라도 업로드 파일에 없으면 해당 항목 실적은 비워 두고
점검표에 기록합니다. 원본의 같은 수업이 여러 출력 항목에 연결되면 생성을 중단합니다.

ZIP에는 결과 엑셀, 매칭 점검표와 사용한 설정 JSON이 포함됩니다.
설정 백업/복원과 최근 30개 버전 조회를 지원하며, 복원도 새로운 버전으로 저장합니다.

## 저장소 설정

별도 설정 없이 로컬에서는 `data/worklog_settings.sqlite3`에 설정과 변경 이력을 저장합니다.
공개 웹 주소로 접속하고 DB가 연결되지 않았다면 브라우저 세션별 임시 설정을 사용합니다.
이때 다른 접속자의 설정과 분리되며, 재접속 후 유지가 보장되지 않으므로 JSON 백업이 필요합니다.
이 파일은 Git에 포함되지 않습니다. 이는 개발용이며 Streamlit Cloud 영구 저장소로
사용하면 안 됩니다. 초기 설정은 두 기본 엑셀 양식에서 한 번만 가져옵니다.
양식을 다시 교체해도 이미 저장한 설정은 덮어쓰지 않습니다.

Neon 연결 시 `.streamlit/secrets.toml` 또는 환경변수에 다음 값을 설정합니다.
실제 비밀번호와 접속 주소는 저장소에 올리지 않습니다.

```toml
DATABASE_URL = "postgresql://USER:PASSWORD@HOST/DATABASE?sslmode=require"
APP_ADMIN_PASSWORD = "관리자용-별도-비밀번호"
```

Streamlit Cloud에서는 앱 관리 화면의 Secrets에 동일한 값을 넣습니다.
`DATABASE_URL`이 있으면 PostgreSQL을 사용하며, 연결 실패 시 로컬 DB로 전환하지 않습니다.
외부 DB가 연결되어 있고 관리자 비밀번호가 없으면 설정은 조회만 가능합니다.
첫 연결 시 테이블과 기본 설정을 초기화합니다. 로컬에서 편집한 설정은 `설정 백업`으로
내보낸 뒤 Neon 연결 후 관리자 화면에서 복원하면 옮길 수 있습니다.
DB에는 양식 설정만 저장하며 업로드한 출결/개인정보는 저장하지 않습니다.
